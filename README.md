# LeetCode Solutions

A collection of LeetCode solutions used for data-structures and algorithms practice and interview preparation.

## What this repository demonstrates

The solutions cover common interview patterns including:

- Arrays and strings
- Hashing
- Two pointers
- Sliding window
- Stack and queue
- Linked lists
- Trees and binary trees
- Graphs
- Recursion and backtracking
- Dynamic programming
- Sorting and searching
- Tries
- String matching and related algorithms

The repository is primarily a record of problem-solving practice rather than a production application.

## Repository Structure

Solutions are organised by the way they are stored in the repository. Each solution should ideally include the problem reference and a clear implementation.

## Approach

For interview preparation, the focus is on:

1. Understanding the problem constraints.
2. Identifying the underlying algorithmic pattern.
3. Writing a correct baseline solution.
4. Analysing time and space complexity.
5. Improving the solution where a better approach exists.
6. Testing edge cases.
